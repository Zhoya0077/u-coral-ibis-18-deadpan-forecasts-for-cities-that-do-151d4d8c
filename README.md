One deadpan weather forecast for a city that does not exist: Varn Hollow, where the rain falls uphill, the low is minus Tuesday, and the council fines the clouds for loitering. A single line, delivered with a straight face.

## Run it

```sh
node main.ts
```

It writes the forecast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), after a self-checking gate confirms the line is 1–160 characters, not only whitespace, and a single line — then reads the file back to verify the exact bytes round-tripped.
